# UI Guidelines

- Keep the Workscope Nepal visual language minimalist, monochromatic, and content-focused.
- Use black, white, and neutral surfaces with semantic shadcn CSS variables.
- Avoid gradients, unnecessary animation, animation libraries, and decorative effects.
- Use shadcn/ui primitives for shared interface elements.
- Use semantic HTML, accessible labels, visible focus states, and responsive layouts.
- Do not create mock company, review, salary, user, or statistics data.
