# Project Plan

## Current Phase

Establish the JavaScript project boilerplate and first frontend authentication foundation for Workscope Nepal.

## Completed Direction

- React and Vite frontend in `frontend/`
- Node.js and Express backend in `backend/`
- Supabase-ready environment variable placeholders
- Minimal frontend shell and backend health check
- Supabase Auth with Google OAuth and global frontend session state
- Protected frontend `/companies` route with a data-free empty state

## Not Yet Implemented

Company data, reviews, salaries, jobs, dashboards, profiles, and database schema are intentionally deferred.
